info À propos de la clé API Gemini

Pour utiliser l'assistant IA, vous devez fournir une clé API Gemini. Cette clé est stockée de manière sécurisée et utilisée uniquement pour vos requêtes.

Comment obtenir une clé gratuite :

  1. Allez sur Google AI Studio
  2. Connectez-vous avec votre compte Google
  3. Cliquez sur "Get API key" ou "Obtenir une clé API"
  4. Copiez la clé et collez-la ci-dessous

💡 Le plan gratuit permet 60 requêtes par minute, ce qui est largement suffisant.
